Several agents.
One office.

The whole setup for running coding agents side by side, out of one box. You see which one needs you, and you never reach for the mouse.

macOS or Linux, paste into a terminal

git clone https://github.com/ZyxWorks/agent-office.git ~/agent-office && ~/agent-office/bin/office tools && ~/agent-office/install.sh

then, every morning

office on

office tools lists every tool you lack and asks before it installs one, each at a pinned version from its own maker. install.sh shows every file it will write and backs up what it replaces. Neither starts anything. You bring git, Node 22.19 or newer, and a coding agent you signed in to yourself, such as Claude Code or Codex. One thing is left to you before the first office on: clone Firstmate and put its path in the config.

MIT licensed, and all of it is on GitHub before you run any of it: the installer is one short script you can read first, and so is the list of everything it installs. Getting started walks you through the first day.

What was in the way

Running three or four coding agents at once is normal now. The tools for it exist, and they are good: herdr runs the terminal and knows each agent's state, Firstmate supervises a fleet of workers, treehouse hands each one its own git worktree. But each is its own install, its own config and its own update, and the wiring between them lived in one person's dotfiles. A new machine meant doing it all again by hand. A new colleague meant "how did you set that up".

Agent Office is that wiring, packaged and tested. It does not rewrite any of those tools. Each one stays with its own maker.

Which one needs you

Every agent has one line in the sidebar. herdr knows whether it is working, idle, done or blocked. The Agent Office meter adds the two numbers that decide what you do next: how full its context is, and how long it has been quiet.

No mouse

One key walks the whole office. Shift+← and Shift+→ go to the pane on that side, and from the last pane to the next tab. Shift+↑ and Shift+↓ do the same, and from the last pane to the next space. It stops at the ends, so you can hold it.

Everything else is Ctrl+Space, then one letter. A small letter is for the space, the same letter with Shift is for the tab.

office keys prints every key on one screen. A probe checks that sheet against herdr itself on every push, so it cannot drift from what the keys really do.

What it does not do

  • No rewrite. herdr, Firstmate, treehouse and the tools around them stay with their own makers and keep their own update paths. Agent Office owns the install, the one config, the tested set of versions and the daily commands.
  • No blind install. A release is downloaded at a pinned version and checked against a pinned SHA-256 before it is unpacked. npm packages install with their scripts off. Nothing is piped into a shell and nothing uses sudo.
  • No overwriting your files. Every change is shown first, what it replaces is backed up, and it asks. Your own herdr config file is never touched.
  • No blanket kill. office off stops the office it started, after it shows you what will stop. It never stops every claude on the machine, and it never deletes a worktree.
  • No signing in for you. You install and authenticate Claude Code, Codex or any other agent yourself. Your accounts and keys never pass through this.
  • No Windows. Agent Office runs on macOS and Linux.
  • No telemetry. Phone notifications are off until you turn them on, and the address they go to exists only in your own config file.

Every command on this page has a probe that runs it in a throwaway home, on macOS and Linux, on every push. The source is public, and so is every claim on this page.
